## 0. 姿态系统机制（改动核心）

- 四种姿态：**愤怒 Wrath / 平静 Calm / 神格 Divinity / 中性 Neutral**。`stances.*Stance`，`STANCE_ID` 分别
  `"Wrath"/"Calm"/"Divinity"/"Neutral"`。
- **hook**：`AbstractPower.onChangeStance(oldStance, newStance)`（也有 `AbstractRelic.onChangeStance`）。
  切换用 `actions.watcher.ChangeStanceAction(stanceId)`。
- **「进入具体姿态」判定**：`!old.ID.equals(new.ID) && !new.ID.equals("Neutral")`。
  **「退出到中性」**（化体/化智为空、神格结束）= `new.ID.equals("Neutral")` → 不算进入。
  模板：`MentalFortressPower`（切换姿态得格挡，判 `old.ID!=new.ID`），改成再排除进入 Neutral。

## 1. 削红蓝（姿态无限）

### 1.1 删猛虎下山 + 新增顺应变化
- **删** 猛虎下山：类名 `Rushdown`、**cardID 是 `"Adaptation"`**（顺应变化是它的前身，改名没改 id）。
  现状：uncommon 能力，1(0) 费，进入愤怒时抽 2 —— 愤怒无限的核心引擎。
  手段：`BaseMod.removeCard("Adaptation", CardColor.PURPLE)`。
- **新增** 顺应变化（`cards.Adaptation`，cardID `MODID:Adaptation`，稀有能力，2(1) 费）：
  - 施加「进入姿态抽 1」power（`AdaptationPower.onChangeStance`：进入具体姿态、非中性 → 抽 1）。
  - 打出时 `ChangeStanceAction("Calm")` 退出当前姿态、进入平静 → 因此**打出即触发一次抽 1**。
  - **特殊**：只对「进入具体姿态」生效；化体/化智为空、神格结束的「退出到中性」不抽。
  - **卡图复用猛虎下山**（`purple/power/rushdown`）——两者本是同一张卡的前后世，渊源极深。
    实现：CustomCard 指向游戏内 Rushdown 卡图（或提取该图到 mod 资源）。
  - 削点：把「进入愤怒抽 2」的强引擎换成「进入任意姿态抽 1、且只算进入」的温和版。

### 1.2 发泄 Tantrum
- 现状：uncommon 攻击，1 费，3 伤 3(4) 次 + **进入愤怒** + 洗回牌库。
- 改为：**2(1) 费**、3 伤 3 次 + 洗回 + **进入愤怒**。需要升级才能成为平费愤怒无限引擎，和初始卡暴怒一致。但洗回牌堆保留了自身作为无限引擎的高效性。`shuffleBackIntoDrawPile` 保留。
- 手段：patch 构造（cost=2）+ upgrade（cost=1）+ 描述。

### 1.3 心灵堡垒 MentalFortress
- 现状：1 费能力，每次切换姿态（含退出到中性）获得 **4(6)** 格挡（`MentalFortressPower`，`magicNumber`）。姿态防御引擎。
- 改为：格挡 **4(6) → 3(5)**（削姿态防御引擎，配合削红蓝）。
- 手段：patch 构造 `magicNumber=3` + upgrade postfix `magicNumber=5`（覆盖原 upgradeMagicNumber(2) 的 6）。

## 2. 增预见

### 2.1 警惕 Vigilance（初始技能）
- 现状：2 费，8(12) 格挡 + 进入平静。
- 改为：**8(11) 格挡 + **（保留进平静）；**升级额外预见 3*。



### 2.2 化智为空 EmptyMind
- 现状：1 费，抽 !M!(2→3) 张 + 退出姿态到中性。
- 改为：退出姿态到中性 + **预见 !M!**（预见数 = 抽牌数）+抽 !M!(2→3) 张 。价值上对齐抽 3(4)，「退出到中性」不提供卡牌价值。先退出姿态、再预见、再抽牌，以保留对“灵光一现”的“预见获得真言”的基本兼容。
- 手段：patch use postfix 加 `ScryAction(magicNumber)` + 描述追加。

### 2.3 迂回 Weave
- 现状：0 费攻击，4(6) 伤；`triggerOnScry` = 预见时从弃牌堆回手。
- 改为：**升级不加伤**，而是获得「抽 1 放回 1到抽牌堆顶」——把预见切实变成「抽到堆顶卡」。


### 2.4 回环踢 WheelKick
- 现状：uncommon 攻击，2 费，15(20) 伤 + 抽 2。
- 改为：**稀有度降为 COMMON**（补顺应变化升金后的过牌荒），效果不变。
- 手段：patch 构造 postfix `rarity = COMMON`。

## 3. 增真言 / 神格

### 3.1 敬拜 Worship
- 现状：2 费，获得 5 真言；升级 `selfRetain`（保留）。真言流里公认最亏费的一张。
- 改为：2 费，**3(5) 格挡 + 预见 3(5) + 获得 5 真言**，保留（升级）。
- 手段：patch use postfix 加 `GainBlockAction(3/5)` + `ScryAction(3/5)` + 描述追加。

### 3.2 圣洁 Sanctity
- 现状：1 费uncommon技能，6(9) 格挡；若本回合上一张打出的是技能牌则抽 2（`SanctityAction`）。
- 改为：**稀有度更改为COMMON。纯原效果 + 获得真言 1(2)**（真言流补一张温和的真言来源）。
- 手段：patch use postfix 加 `ApplyPowerAction(new MantraPower(p, 1/2))` + 描述追加。
